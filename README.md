# AKM Abrar Islam — Technical Portfolio

My Personal portfolio site which I created during my University coursework. Much of the website has been stripped including php, sql, database, login and blog features leaving only static pages for live git site.

## Live site

**https://akm-04.github.io**

## About this site

This site began as coursework for the *Fundamentals of Web Technology* module at Queen Mary University of London and has since been updated into a personal technical portfolio.

It is intentionally kept lightweight and static, using HTML and CSS with no server-side dependencies, so it can be hosted directly with GitHub Pages.
